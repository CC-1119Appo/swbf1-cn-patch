# v1.0 发布说明

首个正式版本，支持 GOG 1.2 / 1.3。

## 亮点

- **界面全汉化**：2118 条文本，含菜单、HUD、任务简报、多人界面、兵种与武器说明；
- **无缺字**：6 套字体重建，1077 个汉字全有位图；
- **过场字幕**：11 段影片烧入中英对照字幕（9 段电影片段 + 2 段开场滚动字幕），
  重编码使用最高质量档，单段体积高于原片，无色块；
- **术语统一**：按 19352 条中英对照表校正 39 处译名（如 欧比-旺·克诺比、千年隼号、义军同盟）；
- **图形安装器**：自动识别版本、备份/还原、安装范围选择，XP SP3+ 可用。

## 已知问题

- HUD 数字为原版贴图，未汉化；
- 主菜单顶部分类标签位置由引擎硬编码，未调整；
- 游戏内对白字幕需手动在选项里开启。
