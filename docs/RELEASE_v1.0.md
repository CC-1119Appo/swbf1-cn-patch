# v1.0 首个正式版

与《前线2》汉化包相同的**单文件安装器**：一个 exe 内含 1.2 / 1.3 两套文本载荷与带字幕的过场影片。

支持 **GOG 1.2 / 1.3** 与 **Steam 版**（均已实测通过）。

## 内容

| 模块 | 说明 |
|---|---|
| 界面与文本 | 2118 条文本汉化：菜单、HUD、任务简报、多人界面、兵种/武器说明 |
| 字体 | 6 套字体重建，1077 个汉字，无缺字 |
| 过场动画 | 11 段影片烧入中英对照字幕，最高质量重编码 |
| 术语 | 按 19352 条星战中英对照表校正 39 处译名 |
| 版本 | 自动识别 GOG 1.2 / 1.3 |
| 安装器 | Win32 图形界面，XP SP3+，支持备份/还原、范围选择、静默安装 |

## 下载

| 文件 | 大小 | 说明 |

## 静默安装

```bat
SWBF1_汉化包_v1.0.exe /S "E:\GOG Games\Star Wars - Battlefront\GameData"
```
