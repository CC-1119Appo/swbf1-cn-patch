# 安装说明

## 单文件安装器

发布包只有一个文件：`SWBF1_汉化包_v1.0.exe`（约 920 MB），
内部已包含 1.2 / 1.3 两套文本载荷与带字幕的 shell.mvs，与《前线2》汉化包形式一致。

## 安装步骤

1. 双击运行；
2. 路径自动填充（GOG / Steam / LucasArts 常见路径）；
3. 点「检测版本」；
4. 选择安装范围：完整安装 / 仅界面汉化 / 仅过场字幕；
5. 保持「安装前备份原版文件」勾选，点「开始安装」。

## 静默安装

```bat
SWBF1_汉化包_v1.0.exe /S "<GameData 路径>"
```

## 还原

界面里点「还原原版」；或手动把 `*.original` 覆盖回 `core.lvl` / `shell.mvs`。

## 常见问题

**Q：双击没反应？**
A：首次运行 Windows Defender 会扫描这个 920 MB 的文件，可能等待数十秒；后续启动会很快。

**Q：提示写入失败？**
A：把游戏目录装到受保护位置（Program Files）时，右键以管理员身份运行。

**Q：安装后界面仍是英文？**
A：确认选的是 `GameData` 目录（里面有 `data/_lvl_pc`）。

**Q：过场没有字幕？**
A：确认安装范围包含字幕，且 `shell.mvs` 大小变为约 869 MB。
