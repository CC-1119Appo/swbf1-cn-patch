# 安装说明

## 环境要求

- Windows XP SP3 / Vista / 7 / 8 / 10 / 11
- 正版 Star Wars: Battlefront (2004)，GOG 1.2 或 1.3

## 安装步骤

1. 解压发布包，保持结构：

```text
SWBF1_汉化包_v1.0/
  安装_汉化包.exe
  README.md
  payload/
    core.lvl        25.1 MB（1.3）
    core.lvl.12     25.1 MB（1.2）
    shell.mvs      869.7 MB
```

2. 双击 `安装_汉化包.exe`；
3. 路径自动填充，若未识别点「浏览…」选择 `...\Star Wars - Battlefront\GameData`；
4. 点「检测版本」，确认界面/影片状态与备份情况；
5. 选择安装范围：
   - 完整安装（界面 + 过场字幕）
   - 仅界面汉化
   - 仅过场字幕
6. 保持「安装前备份原版文件」勾选，点「开始安装」。

## 还原

点「还原原版」用 `*.original` 覆盖；如果安装时取消了备份，则无法自动还原。

## 常见问题

**Q：安装后界面还是英文？**
A：确认选择的是游戏根目录下的 `GameData`，不是游戏安装根目录。

**Q：安装提示写入失败？**
A：右键以管理员身份运行。

**Q：过场动画没有字幕？**
A：确认安装范围包含「过场字幕」，且 `data/_lvl_pc/movies/shell.mvs` 大小变为约 869 MB。

**Q：游戏内对白没有字幕？**
A：游戏设置里「选项 → 音频选项 → 字幕」需要手动开启。
